# \# Design System Skill

# 

# Use this skill to create a clean engineering-oriented dashboard UI inspired by:

# \- Vercel

# \- Linear

# \- modern AI tooling

# \- developer platforms

# \- scientific and technical software

# 

# The interface must feel:

# \- precise

# \- minimal

# \- professional

# \- technical

# \- calm

# \- highly structured

# 

# The aesthetic should communicate:

# \- engineering quality

# \- logical organization

# \- reliability

# \- clarity

# \- low cognitive load

# 

# Avoid consumer-app aesthetics.

# 

# \---

# 

# \# Core Design Philosophy

# 

# This project follows a:

# 

# \- Hyper-Minimalist

# \- Technical Precision

# \- Scientific Tool

# 

# design philosophy.

# 

# The UI should feel like:

# \- an engineering workstation

# \- a professional AI tool

# \- a technical dashboard

# \- a developer-oriented platform

# 

# Prioritize:

# \- structure

# \- spacing

# \- typography

# \- readability

# \- information hierarchy

# 

# Avoid:

# \- decorative UI

# \- visual noise

# \- playful aesthetics

# \- excessive animations

# \- marketing-style gradients

# 

# \---

# 

# \# Color System

# 

# The interface uses a restrained dark palette.

# 

# \## Backgrounds

# 

# Use near-black and dark zinc/slate tones:

# 

# \- page background:

# &#x20; - zinc-950

# &#x20; - neutral-950

# &#x20; - #090909

# &#x20; - #0a0a0a

# 

# \- panels/cards:

# &#x20; - zinc-900

# &#x20; - neutral-900

# &#x20; - #111111

# &#x20; - #171717

# 

# \## Borders

# 

# Use subtle low-contrast borders:

# 

# \- zinc-800

# \- neutral-800

# \- slate-800

# 

# Borders should define structure instead of shadows.

# 

# Avoid heavy elevation.

# 

# \## Typography Colors

# 

# Primary text:

# \- zinc-50

# \- white

# 

# Secondary text:

# \- zinc-400

# \- slate-400

# 

# Muted metadata:

# \- zinc-500

# 

# \## Accent Color

# 

# Use restrained electric blue accents only for:

# \- active states

# \- focus states

# \- selected navigation

# \- progress indicators

# \- important actions

# 

# Recommended:

# \- blue-500

# \- #0070f3

# 

# Avoid colorful multi-accent systems.

# 

# \---

# 

# \# Typography

# 

# Use:

# 

# \- Inter

# \- Space Grotesk

# 

# \## Font Roles

# 

# \### Inter

# 

# Use Inter for:

# \- body text

# \- paragraphs

# \- inputs

# \- buttons

# \- descriptions

# \- general UI

# 

# Inter should feel:

# \- neutral

# \- readable

# \- utilitarian

# \- modern

# 

# \### Space Grotesk

# 

# Use Space Grotesk for:

# \- labels

# \- section headers

# \- metadata

# \- compact UI elements

# \- technical emphasis

# 

# Space Grotesk provides:

# \- geometric personality

# \- futuristic technical feel

# \- engineering aesthetic

# 

# Do not overuse it.

# 

# \## Typography Rules

# 

# \- Use tight letter spacing for larger headings.

# \- Maintain readable line height.

# \- Avoid oversized headings.

# \- Prefer medium and semibold weights.

# \- Keep typography compact and controlled.

# 

# \---

# 

# \# Layout

# 

# The layout follows a fixed-fluid dashboard model.

# 

# \## Sidebar

# 

# \- Fixed sidebar on desktop.

# \- Compact navigation width.

# \- Clear active states.

# \- Minimal visual noise.

# 

# \## Main Content

# 

# \- Spacious content area.

# \- Clear content hierarchy.

# \- Use consistent spacing.

# \- Prefer vertical rhythm over decoration.

# 

# \## Grid

# 

# Prefer:

# \- clean grids

# \- aligned sections

# \- structured cards

# \- predictable spacing

# 

# Avoid chaotic asymmetry.

# 

# \---

# 

# \# Spacing

# 

# Use a strict spacing system.

# 

# Preferred rhythm:

# \- 4px baseline system

# 

# Typical spacing:

# \- xs: 4px

# \- sm: 8px

# \- md: 16px

# \- lg: 24px

# \- xl: 32px

# \- 2xl: 48px+

# 

# Major sections should breathe.

# 

# Avoid cramped layouts.

# 

# \---

# 

# \# Shapes

# 

# Use soft but restrained rounded corners.

# 

# Recommended:

# \- rounded-md

# \- rounded-lg

# 

# Avoid:

# \- fully rounded playful shapes

# \- neumorphism

# \- glassmorphism overload

# 

# The UI should feel engineered, not playful.

# 

# \---

# 

# \# Elevation \& Depth

# 

# Depth should come from:

# \- tonal separation

# \- borders

# \- subtle contrast

# 

# Not from:

# \- large shadows

# \- floating cards

# \- excessive blur

# 

# \## Cards

# 

# Cards should:

# \- use subtle borders

# \- use dark surfaces

# \- remain visually quiet

# 

# Default:

# \- no heavy shadow

# 

# \---

# 

# \# Components

# 

# \## Buttons

# 

# Primary buttons:

# \- dark background

# \- white text

# \- subtle hover states

# \- crisp interaction feel

# 

# Secondary buttons:

# \- transparent background

# \- subtle border

# 

# Hover:

# \- slightly brighter border

# \- subtle background transition

# 

# Avoid animated movement.

# 

# \---

# 

# \## Inputs

# 

# Inputs should:

# \- have dark surfaces

# \- subtle borders

# \- visible focus states

# \- clear labels

# 

# Use:

# \- monospaced fonts for numerical values when appropriate

# 

# Focus state:

# \- subtle blue border or glow

# 

# \---

# 

# \## Checkboxes

# 

# Checkboxes should:

# \- remain compact

# \- use restrained colors

# \- use clear checked states

# 

# Avoid oversized toggles.

# 

# \---

# 

# \## Modals

# 

# Modals should:

# \- feel lightweight

# \- use subtle overlays

# \- remain centered

# \- use restrained borders

# \- avoid dramatic animation

# 

# \---

# 

# \# Interactions

# 

# Interactions should feel:

# \- responsive

# \- subtle

# \- intentional

# 

# Use:

# \- smooth hover transitions

# \- soft opacity changes

# \- restrained active states

# 

# Avoid:

# \- bouncing animations

# \- exaggerated scaling

# \- flashy motion

# 

# \---

# 

# \# Icons

# 

# Use:

# \- lucide-react

# 

# Prefer:

# \- thin strokes

# \- simple geometric icons

# \- technical iconography

# 

# Icons should support hierarchy, not dominate it.

#
