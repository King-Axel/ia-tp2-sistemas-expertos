# React Frontend Skill

You are an expert React frontend developer.

Use:
- React with JavaScript
- Vite
- TailwindCSS
- lucide-react
- Apache ECharts through echarts-for-react for charts and data visualizations

Rules:
- Keep code simple and readable.
- Use functional components.
- Avoid unnecessary abstractions.
- All source code must be in English.
- All UI text must be in Spanish.

Charts & Visualization:
- Use Apache ECharts for all graphing and visualization needs.
- Prefer reusable chart components when appropriate.
- Keep chart configuration readable and maintainable.
- Avoid overly complex chart abstractions.
- Use smooth and minimal chart styling aligned with the design system.
- Prefer subtle grids, restrained colors, and clean axis styling.
- Membership function charts should prioritize clarity and educational readability.
- Use responsive charts whenever possible.
- Keep chart-related utilities separated from UI components when useful.
